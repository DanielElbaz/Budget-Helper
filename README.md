# Budget Helper

Application web pour gérer tes dépenses, tes revenus et tes budgets par catégorie.

## Fonctionnalités

- Suivi des revenus et dépenses avec catégories personnalisables (icône + couleur)
- Transactions récurrentes (hebdo / mensuel / annuel)
- Budgets mensuels par catégorie avec barres de progression et alertes de dépassement
- Dashboard : revenus vs dépenses du mois, reste à vivre, répartition par catégorie, évolution sur 6 mois
- Toutes les données restent en local dans le navigateur (IndexedDB), aucun serveur requis

## Stack

- React + TypeScript + Vite
- Tailwind CSS v4
- Dexie.js (IndexedDB)
- Recharts
- React Router

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
